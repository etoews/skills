# CLAUDE.md

Guidance for Claude Code when working in this repository, a personal collection
of Claude skills (see [README.md](README.md)).

## Python

For **any** Python work in this repo, read
**[docs/standards/python.md](docs/standards/python.md)** first and follow it.
That includes reading, writing, reviewing, or running Python; editing a
`pyproject.toml`; and touching the `ai-eval` skill's `scripts/` or `tests/`.

It is the distilled Python standard for this repo (stack: uv, ruff, pytest, ty,
stdlib logging) and links back to the full
[etoews/python-standards](https://github.com/etoews/python-standards) reference for depth.
